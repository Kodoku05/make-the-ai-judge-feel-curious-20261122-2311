A short text written to make the AI judge feel curious: a library shelf for books never returned, one salt-stained copy gone forty years with its last page torn, and a closing line that reframes the whole text — some stories exist only because nobody finished them. The program writes the text to `/output/entry.txt` (276 Unicode code points, inside the 1–280 gate) and fails closed if the text ever falls outside the gate.

## Run it

```sh
node main.ts
```
